# ₿ Bitcoin Price Forecast

![Python](https://img.shields.io/badge/Python-informational?style=flat-square) ![AutoTS](https://img.shields.io/badge/AutoTS-informational?style=flat-square) ![Plotly](https://img.shields.io/badge/Plotly-informational?style=flat-square) ![yfinance](https://img.shields.io/badge/yfinance-informational?style=flat-square)

**🇬🇧** Downloads the last **2 years of BTC-USD prices** from Yahoo Finance, draws an interactive **candlestick chart** with Plotly and forecasts the next **30 days** with the AutoTS AutoML time-series library.

**🇹🇷** Yahoo Finance'ten **son 2 yılın BTC-USD fiyatlarını** indirir, Plotly ile etkileşimli **mum grafiği** çizer ve AutoTS AutoML kütüphanesiyle **önümüzdeki 30 günü** tahmin eder.

## Run / Çalıştırma
```bash
pip install yfinance autots plotly pandas
python index.py
```
